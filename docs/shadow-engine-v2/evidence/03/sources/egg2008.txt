Regional Models
Europe (EGG2008)
Authors:
H. Denker, et al.
Created:
2008
Resp:
H. Denker
Status:
PUBLIC
Description:
The EGG2008 quasigeoid data are stored in gridded form in 
								  the ASCII file EGG2008-qg_g10m15m. The grid spacing of the file is 10' x 15'. 
								  The full resolution file (1.0' x 1.0') is not available as public domain data 
								  and must be obtained through the IAG Secretary General. At the beginning of 
								  the file there is a grid label with the min. and max. latitude and longitude of 
								  the grid area as well as the grid spacing in latitude and longitude direction 
								  (units are degrees). The grid values are given in rows from West to East. 
								  The rows are given from North to South. Thus, the first data value refers to 
								  the NW corner of the grid, and the last data value refers to the SE corner of 
								  the grid. The grid values are given in mm. The Fortran format is 10i7. The values 
								  refer to GRS80 and the zero tide system (as recommended by IAG); furthermore, 
								  the values are compatible with the European Vertical Reference Frame 
								  2007 (EVRF2007).
