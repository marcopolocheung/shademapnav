Description
CHMv2 is a global 1-meter resolution canopy height map derived from Maxar Vivid2 satellite imagery using a DINOv3-based depth estimation model trained on airborne laser scanning data. The dataset covers nearly the entire global land surface and is available via the AWS Open Data Registry.
